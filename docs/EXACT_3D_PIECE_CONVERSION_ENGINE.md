# Exact 3D Piece Conversion Subsystem (Phase 86)

## 1. Architectural Overview & Context

The **Exact 3D Piece Conversion Subsystem** converts 2D puzzle pieces generated by the Automatic 2D Generation System into exact, watertight 3D solid pieces.

### 1.1 Conversion Pipeline
```
GeneratedPuzzle2D
        ↓
Stage 1: Piece Profiles (ProfileExtractor)
        ↓
Stage 2: Extrusion (SolidExtruder with Ear Clipping)
        ↓
Stage 3: 3D Solids (SolidRepresentation3D & Mesh Buffers)
        ↓
Stage 4: Local Coordinate Frames (CoordinateFrameAssigner)
        ↓
Stage 5: 3D Validation (Validator3D)
```

### 1.2 Core Architectural Principles
1. **Independent Local Coordinates**: Each piece exists strictly in its own local coordinate system ($z \in [-thickness/2, +thickness/2]$). No final 3D assembly positions or global assembly transforms are assigned at this stage.
2. **Watertight Manifold Solids**: Top face ($+Z$), bottom face ($-Z$), and side wall quads form a closed, manifold boundary representation with zero holes or unstitched edges.
3. **Retained Metadata Integrity**: Every piece strictly retains:
   - Piece ID
   - Interface IDs
   - Connector IDs
   - Material specification
   - Stock thickness
   - Local coordinate frame
4. **Deterministic Validation**: Rigorous verification of profile closure, solid manifoldness, thickness conformity, and connector geometry validity.

## 2. Pipeline Stages

### Stage 1: Piece Profiles
Extracts the exact 2D physical boundary with tabs and slots. Validates counter-clockwise (CCW) winding, eliminates duplicate collinear points, and computes the 2D centroid to normalize coordinates around local $(0,0)$.

### Stage 2: Extrusion
Performs planar triangulation using the Ear Clipping algorithm:
- Top face at $z = +T/2$ with $+Z$ normal.
- Bottom face at $z = -T/2$ with $-Z$ normal and reversed winding.
- Side wall quads connecting adjacent boundary vertices between top and bottom planes with outward surface normals.

### Stage 3: 3D Solids
Calculates exact physical properties:
- $\text{Volume} = \text{Area}_{2D} \times T$
- $\text{Surface Area} = 2 \times \text{Area}_{2D} + \text{Perimeter}_{2D} \times T$
- $\text{Mass} = \text{Volume} \times (\text{Density} \times 0.001)$
- $\text{Bounds} = \text{Box3D}[\min, \max]$

### Stage 4: Local Coordinate Frames
Assigns the canonical orthonormal frame $F = (\text{origin}, \vec{t}, \vec{n}, \vec{b})$ with $\text{origin} = (0,0,0)$, $\vec{t} = (1,0,0)$, $\vec{n} = (0,1,0)$, and $\vec{b} = (0,0,1)$. Re-bases all attached canonical interfaces into the piece's local frame.

### Stage 5: 3D Validation
Validates:
- **Closed Profile**: Non-degenerate, $\ge 3$ vertices, non-zero area, closed loop.
- **Valid Solid**: Non-empty position/normal/index buffers, positive volume, positive surface area, valid bounding box.
- **Correct Thickness**: Thickness $> 0$, mesh $Z$-span strictly matches stock thickness.
- **Valid Connector Geometry**: Tab/slot dimensions $> 0$, valid clearance, complementarity ($W_{\text{slot}} \ge W_{\text{tab}}, D_{\text{slot}} \ge D_{\text{tab}}$).

## 3. Data Model

### 3.1 GeneratedPiece3D
```typescript
export interface GeneratedPiece3D {
  pieceId: ID;
  name: string;
  interfaceIds: string[];
  connectorIds: string[];
  material: {
    id: string;
    name: string;
    stockThicknessMm: number;
    kerfMm: number;
  };
  thickness: number;
  localCoordinateFrame: CoordinateFrame3D;
  profile: ExtrudablePieceProfile;
  solid: SolidRepresentation3D;
  interfaces: CanonicalInterface[];
  connectorParameters: ConnectorParameters[];
  sheetCentroid: Vec2;
  neighborPieceIds: string[];
  isBorderPiece: boolean;
}
```

## 4. Usage Example

```typescript
import { Automatic2DGenerationEngine } from "@/core/puzzle/automatic2d";
import { Piece3DConversionEngine } from "@/core/puzzle/piece3d";

// 1. Generate 2D puzzle
const puzzle2D = Automatic2DGenerationEngine.generatePuzzle({
  overallSize: { widthMm: 400, heightMm: 400 },
  targetPieceCount: 16,
  partitionStyle: "rectangular",
  preferredConnectorType: "tab_slot",
});

// 2. Convert to exact 3D solid pieces
const puzzle3D = Piece3DConversionEngine.convertPuzzle(puzzle2D);

console.log(`Converted ${puzzle3D.pieces.length} 3D pieces.`);
console.log("Validation Status:", puzzle3D.validation.isValid);

for (const piece of puzzle3D.pieces) {
  console.log(`Piece ${piece.pieceId}: Volume = ${piece.solid.volumeMm3} mm^3, Thickness = ${piece.thickness} mm`);
}
```
