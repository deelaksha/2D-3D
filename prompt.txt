# COMPLETE PROJECT REQUIREMENT

# AI-Based Wooden Puzzle Image Understanding, 3D Reconstruction and Assembly System

## 1. PROJECT OBJECTIVE

Build a local-first AI system that takes an image/photo of wooden laser-cut puzzle/toy pieces and reconstructs those pieces as accurate 3D components, determines how the pieces connect, and produces a final assembled 3D model.

The target examples are wooden mechanical/assembly puzzles such as:

* wooden 3D puzzle toys
* laser-cut wooden models
* wooden construction kits
* mechanical wooden toys
* interlocking wooden pieces
* tabs and slots
* pegs and holes
* gears
* panels
* circular components
* flat wooden parts that are assembled into 3D structures

The system does NOT need to be a generic "AI image-to-3D generator."

The system should instead use AI for:

1. image understanding
2. piece identification
3. connector identification
4. visual reasoning
5. assembly planning

And deterministic geometry algorithms for:

1. extracting contours
2. creating precise 2D geometry
3. extruding pieces into 3D
4. creating holes
5. creating tabs/slots
6. positioning pieces
7. checking collisions
8. assembling pieces
9. exporting GLB/OBJ/STL

The primary goal is:

IMAGE → UNDERSTAND → EXTRACT PIECES → CREATE 3D PIECES → DETERMINE CONNECTIONS → ASSEMBLE → GLB

# 5. IMPORTANT DESIGN PRINCIPLE

Do NOT ask an LLM to hallucinate precise geometry.

AI:

UNDERSTANDS

Geometry engine:

CALCULATES

Assembly engine:

VALIDATES

This is extremely important.

For example:

Qwen2.5-VL should say:

"Piece A has a rectangular outline with one tab on the top."

The geometry engine should calculate:

* exact polygon
* thickness
* extrusion
* hole geometry
* tab geometry
* mesh vertices

The assembly engine should calculate:

* translation
* rotation
* connector alignment
* collision
* final placement

# 50. TRAINING PHILOSOPHY

Do not train the models just because training is possible.

First create a working baseline.

Then identify exactly what fails.

Then create training data for those failures.

Then perform LoRA/QLoRA fine-tuning.

The objective is not to create a generally intelligent model.

The objective is:

HIGH ACCURACY ON THE USER'S WOODEN PUZZLE DOMAIN.
