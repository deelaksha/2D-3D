[200~# House Architecture 2D-to-3D Training Data System[in my cuirrent my own 3d]

## Project Goal

Build a completely separate, reusable training-data generation and management system for architectural / house-related 2D-to-3D AI training.

The existing 2D-to-3D application is located at:

`/home/sonic-claude2/mythra/2D-3D`

DO NOT mix the training dataset, dataset-generation scripts, generated images, annotations, meshes, or training checkpoints into that directory.

Create a separate project:

`/home/sonic-claude2/mythra/house-3d-training-data`

The purpose of this project is to generate, organize, validate, version, and eventually fine-tune models using high-quality house/architecture data.

The architecture must be designed so that additional datasets can be added later without changing the existing house dataset.

---

# 1. PRIMARY OBJECTIVE

Build a reusable architecture training-data pipeline capable of producing structured samples for:

```text
2D Image
    ↓
Architectural component understanding
    ↓
Semantic component
    ↓
Dimensions
    ↓
Geometry
    ↓
3D mesh
    ↓
Position
    ↓
Rotation
    ↓
Relationships
    ↓
Assembly information
```

The initial dataset should focus on houses and architectural components.

The long-term objective is to train models that can eventually understand:

```text
2D house image
        ↓
identify architectural components
        ↓
decompose the building
        ↓
estimate dimensions
        ↓
generate components
        ↓
position components
        ↓
assemble components
        ↓
generate complete 3D house
```

# 3. HOUSE DATASET STRUCTURE

Create:

```text

├── raw/
├── generated/
├── processed/
├── annotations/

├── segmentation/
├── scenes/
├── metadata/
├── train/
├── validation/
├── test/
└── rejected/
```

Each directory has a clear purpose.

### raw/

Human-collected or externally obtained source data.

Never modify raw data.

### generated/

Synthetic Blender-generated data.

### processed/

Normalized data after preprocessing.

### annotations/

Structured labels and metadata.

### meshes/

Ground-truth 3D geometry.

### renders/

Rendered 2D views.

### depth/

Depth maps.

### segmentation/

Semantic and instance masks.

### scenes/

Complete architectural scene descriptions.

### metadata/

Dataset statistics and indexes.

### train/

Training samples.

### validation/

Validation samples.

### test/

Held-out evaluation samples.

### rejected/

Invalid samples and the reason they were rejected.

# 42. TRAINING TASKS

Generate several training tasks from the same ground-truth scene.

### Task A

Image → category

### Task B

Image → component list

### Task C

Image → dimensions

### Task D

Image → relationships

### Task E

Image → assembly graph

### Task F

Image → room structure

### Task G

Image → architectural description

### Task H

Image → 3D reconstruction plan

### Task I

Image + scene → detect errors

### Task J

Image + incorrect scene → propose corrections

This makes the dataset much more useful than simple image classification.
